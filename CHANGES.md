# Differences from the original Power BI report

1. **Health status donuts** show the *number of KPIs* in each status. The original sized slices by average achievement %, which is hard to read.
2. **Financial "health" bar chart** shows achievement % per KPI, coloured by status, with a 100% reference line.
3. **Sustainability cards** show sustainability metrics. In the original, this page repeated the Customer cards.
4. **Net Promoter Score and Total Employees cards** use the average. The original summed them across months, which is not meaningful for these metrics.
5. **Year filter** is one global control instead of one per page.
6. **Added** a KPI Dictionary page.
